 Online Quiz and Examination System

 Project Description
This project is a Java-based command-line application for conducting online quizzes and managing student results.

Features
- Student registration
- Student login
- Multiple-choice Java quiz
- Automatic score calculation
- Result display
- Result history saved in a file
- Admin login
- Admin quiz information
- View registered student
- View result history

 Technologies Used
- Java
- File Handling
- Command Line Interface

 Requirements
- JDK 17 or above
- Command Prompt / Terminal

 How to Run

Open the project folder in Command Prompt.

Compile the program:

    javac Main.java

Run the program:

    java Main

Admin Login

Username: admin  
Password: 1234

 Quiz
The quiz contains 10 multiple-choice questions related to Java programming. The system automatically calculates and displays the student's score.

 Result Storage
Quiz results are stored in a text file named results.txt.
